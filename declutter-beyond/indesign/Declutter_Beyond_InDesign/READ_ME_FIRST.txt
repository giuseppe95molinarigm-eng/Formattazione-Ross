DECLUTTER BEYOND (Alex Lee), 6 x 9 in print interior: InDesign source
====================================================================

Contents
  Declutter_Beyond_Interior_6x9.idml   InDesign document (IDML package)
  Links/                               placed images (keep next to the file)
  Document fonts/                      EB Garamond and League Gothic (SIL Open Font License)

How to open
  1. In InDesign: File > Open > Declutter_Beyond_Interior_6x9.idml
  2. Save it as an InDesign document: File > Save As > .indd (same folder).
  3. Links panel: all images should show as linked. If any show as missing,
     select them and use "Relink to Folder" > Links.

Fonts (the same as Book 1, "Declutter Your Home, Calm Your Life")
  EB Garamond (body), Avenir Book / Medium / Black (headings),
  League Gothic and Adobe Caslon Pro Italic (title page).
  EB Garamond and League Gothic are included in "Document fonts".
  Avenir and Adobe Caslon Pro are commercial fonts and are not included.
  They are the fonts used in Book 1, so they should already be installed
  on the machine that produced it.

Structure
  Master pages   A-Body (running heads), B-Opener (folio at the foot, used on
                 chapter openings and the contents), C-Appendix.
  Running heads  Left pages: page number + book title. Right pages: the
                 chapter title, taken automatically from the "Chapter Title"
                 paragraph style (text variable), + page number.
  Numbering      i-iv for the front matter, then 1-155 from the Introduction.
  Styles         All text uses paragraph and character styles (Body,
                 Body Drop Cap, Heading 1/2, Key Line, Script, Epigraph,
                 Chapter Label/Title, Phase Number/Name, TOC ...).
  Stories        Each chapter is one threaded story across its own pages.
                 Chapters start on right-hand pages, as in Book 1.

Before export, check
  - Each chapter's last frame has no overset text (no red "+" at the
    frame's lower right). InDesign's composer may break lines slightly
    differently from the approved PDF. If a chapter overflows, add a spread
    after its last page and thread the frame.
  - The Table of Contents page numbers are typed text, matching the
    approved PDF. Update them if pagination changes.
  - Placeholder to replace: the Amazon review link "...asin=YOUR_ASIN"
    (A Note From Me to You).

Export for KDP
  File > Export > Adobe PDF (Print), preset PDF/X-1a:2001,
  no crop marks, no bleed, all pages (not spreads).
