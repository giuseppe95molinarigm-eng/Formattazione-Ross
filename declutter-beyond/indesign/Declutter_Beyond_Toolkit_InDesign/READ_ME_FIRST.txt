THE DECLUTTER BEYOND TOOLKIT: printable workbook (US Letter), InDesign source
=========================================================================

Contents
  Declutter_Beyond_Toolkit_Letter.idml  InDesign document (IDML package)
  Links/                                placed images (keep next to the file)
  Document fonts/                       EB Garamond and League Gothic (SIL OFL)

How to open
  File > Open > Declutter_Beyond_Toolkit_Letter.idml, then File > Save As
  .indd. Fonts as in the main book: Avenir and Adobe Caslon Pro are not
  included (commercial fonts, the same as Book 1).

Structure
  Single pages (not facing), 1 in margins, for home printing.
  Masters: A-Worksheet (running head "Worksheet N: Title" built from two
  text variables), B-Part (title only), C-Opener (folio at the foot).
  Writing lines are empty paragraphs in the "Writing Line" style, with a
  paragraph rule. To add or remove lines, add or delete empty paragraphs.
  The first lines after each question use "Writing Line Keep", so a
  question is never separated from its first lines.

Export
  File > Export > Adobe PDF (Print), preset High Quality Print, all pages.
